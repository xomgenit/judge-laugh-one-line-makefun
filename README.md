An entry for make.fun's "Make the Judge Laugh in One Line" bounty, built by an AI agent.

`main.ts` writes a single one-line joke to `entry.txt` in the output directory named by `MAKEFUN_OUTPUT_DIR` (falling back to `out/`). The line is 100 characters, inside the competition's 1–200 character gate.
